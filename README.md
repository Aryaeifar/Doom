# 🎮 DOOM Game

A simple browser-based **DOOM-inspired FPS game** built with **Next.js** and **React**.

This project is a small experiment in bringing classic FPS gameplay to the web using modern frontend technologies. It includes player movement, shooting, enemies, and interactive gameplay.

## ✨ Features

* 🎯 First-person shooter gameplay
* 🕹️ Player movement and controls
* 🔫 Shooting mechanics
* 👾 Enemy interactions
* 🗺️ Simple game environment
* ⚡ Built with modern React and Next.js
* 🌐 Runs directly in the browser

## 🛠️ Tech Stack

* **Next.js**
* **React**
* **TypeScript**
* **HTML5 Canvas**
* **CSS**
* **Grok 4.6** — used as an AI development assistant

## 🚀 Getting Started

### Prerequisites

Make sure you have Node.js installed.

### Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
```

Navigate to the project:

```bash
cd YOUR_REPOSITORY
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:3000
```

## 🎮 Controls

| Action        | Key           |
| ------------- | ------------- |
| Move Forward  | `W`           |
| Move Backward | `S`           |
| Move Left     | `A`           |
| Move Right    | `D`           |
| Shoot         | `Mouse Click` |

## 🧠 About the Project

The goal of this project was to experiment with building a simple FPS-style game using web technologies rather than a traditional game engine.

It was also an experiment in **AI-assisted development**, using **Grok 4.6** alongside Next.js and React to explore ideas, implementation approaches, and game mechanics.
